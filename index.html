Configurer la synchronisation

La synchronisation utilise un projet Firebase gratuit (Google) comme relais entre vos appareils. Il vous faut environ 5 minutes pour le créer une seule fois.

  1. Allez sur console.firebase.google.com, créez un projet (gratuit, sans carte bancaire)
  2. Dans le projet → Firestore Database → Créer une base → mode production
  3. Dans Authentication → Sign-in method → activez Anonyme
  4. Dans Paramètres du projet → ajoutez une appli Web (icône </>) → copiez le bloc firebaseConfig
  5. Collez ce bloc ci-dessous

Code de synchronisation

Créez un nouveau code sur ce premier appareil, puis saisissez ce même code sur vos autres appareils pour les relier.
